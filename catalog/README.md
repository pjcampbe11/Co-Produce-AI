# Song catalog

Per-song **reference** files generated by
[`scripts/playlist_catalog.py`](../scripts/playlist_catalog.py) from a
`playlist_meta.py --format json` export.

Each `<Artist> - <Title>.json` holds **metadata only** — album, year, producer,
ISRC, Spotify URL, and the **Genius page URL** where the lyrics live. `INDEX.md`
is the browsable table.

**No lyrics are stored here.** The Genius API doesn't serve lyric text, and
commercial song lyrics are copyrighted — so this catalog links to them on Genius
rather than reproducing them. To train a lyric model, use **your own** written
lyrics (`scripts/lyric_analyze.py`).

## Generate

```powershell
$env:GENIUS_TOKEN = "your_client_access_token"
python scripts/playlist_catalog.py --json playlist_full.json --out catalog --resume
```

`--resume` skips songs already done; `--limit N` does a batch; `--index-only`
just rebuilds `INDEX.md`. ~3,400 songs ≈ 20+ min (one Genius call each).
